# 小米音箱私人助理

> **English: [README.EN.md](README.EN.md)**　|　**详细手册：[docs/手册.md](docs/手册.md)**

把 Xiaomi 智能音箱 Pro 变成一个由你自己掌控的 AI 助理：大模型由你选，会联网查资料、按你的习惯每天播报、记得你的偏好；放歌、放电台、讲故事、控制家电都用一句话搞定。所有设置都在一个网页控制台里完成，对话和配置都存在你自己的服务器上。

目前只在 **Xiaomi 智能音箱 Pro（OH2P）固件 `1.62.2`** 上测试通过，其他型号和固件需要自行适配并承担风险。

## 四步装好

### 1. 刷补丁固件

这一步要接数据线、用刷机工具，**有变砖风险，请先看清楚**：[deploy/README.md](deploy/README.md)。刷完之后音箱能 SSH 登录，后面三步都是敲命令。

这是整个过程里唯一麻烦的一步。

### 2. 起一个控制台

在你自己的服务器、Mac mini 或者任何一台常开的电脑上：

```bash
git clone https://github.com/Larryxu001/xiaomi-speaker.git
cd xiaomi-speaker/console && docker compose up -d
```

打开 `http://这台机器的地址:8088`，设一个管理密码。

> 音箱要能访问到这个地址。放在公网请套一层 HTTPS，做法见 [console/README.md](console/README.md)。

### 3. 一条命令装音箱

登录控制台，「概览」页上的**接入音箱**里有一条已经填好你的地址和令牌的命令，复制下来，在能 SSH 到音箱的电脑上执行，把 IP 换成音箱的：

```bash
curl -fsSL https://raw.githubusercontent.com/Larryxu001/xiaomi-speaker/main/deploy/install.sh | sh -s -- \
  --speaker root@192.168.1.100 \
  --console https://你的控制台地址 \
  --token 控制台上的设备令牌
```

它会自动下载编译好的音箱程序、装好脚本、写好配置、启动，并检查是否真的跑起来了。

> 服务器访问不了 GitHub 时，自己编译后加 `--binary 程序路径`，见 [docs/手册.md](docs/手册.md)。

### 4. 填密钥

回到控制台的「模型与密钥」页，填上语音识别和大模型的服务商和 Key（推荐 DeepSeek，便宜且快）。大约 20 秒后音箱就会用上。

喊一声「小爱同学」，开始用。

## 能做什么

**对话**
- 听懂你说的话交给你选的大模型（DeepSeek 等 OpenAI 兼容服务，或 Anthropic 兼容服务）回答；需要时会联网搜索。
- 每句话都交给大模型判断，**怎么说都行**，不用背固定句式。
- 「停止」「暂停」不经过网络，立刻执行；大模型连不上时，音量、切歌、开关家电、问时间仍然可用。
- 快捷指令：给常做的一串事起个短名字，比如说「晚安」就关空调、调小音量、放助眠电台。

**每天主动帮你**
- 定时任务：固定提醒，或从 NewsNow 热榜、RSS、RSSHub、网页生成口播；可以勾选多个平台，按顺序各播前 10 条。
- 记忆：记住你的偏好，回答时自然地用上。
- 点子：每天晚上根据你的记忆、对话和任务，想几个音箱能帮你做的事，放在控制台由你决定要不要。

**听的**
- 音乐：网易云、QQ 音乐、酷狗（用你自己的账号扫码登录）、自建曲库（Subsonic/Navidrome）。
- 网络电台：全世界的公开电台，可收藏、按分类浏览。
- 有声内容：喜马拉雅、蜻蜓 FM、儿童故事等交给小爱原生服务播放，用的是你小米账号绑定的会员权益。
- AirPlay：可以当作 iPhone、Mac 的 AirPlay 音箱。

**家电**
- 米家设备通过小爱原生的云端执行（只发文字指令，不重新打开原生语音）。
- 也可以通过 MCP 接入 Home Assistant 等扩展工具。

**控制台**
- 网页上管理模型与密钥、定时任务、快捷指令、点子、记忆、音乐、电台、应用和扩展工具。
- 底部播放条显示正在放什么，可以暂停、切换、停止、调音量。
- 还能看到响应速度和被跳过的播报，功能悄悄坏掉能及时发现。
- 音箱每 20 秒主动来取一次新设置，控制台从不主动连音箱。

## 工作方式

```text
真实麦克风 → 固件原生 mipns（唤醒词、回声消除、降噪、VAD）
          → speech.usock → xiaoai-agent（音箱上，Rust）
          → 语音识别 → 大模型 + 工具
          → 语音播报（原生音色或控制台合成的音色）
                ↕
          网页控制台（你的服务器，FastAPI）
```

麦克风仍由固件自己的语音前端处理，所以唤醒和回声消除效果和原厂一样；原生小爱听不到你说话，不会抢答。接管在运行时完成，不改动 rootfs，停用后原生小爱立即恢复。

## 代码结构

```text
.
├── xiaoai-agent/          # 音箱上运行的 Agent（Rust）
├── console/               # 网页控制台（FastAPI + Docker）
├── deploy/                # 刷机补丁、install.sh、音箱脚本
├── apps/                  # 控制台「应用」页可一键安装的自托管应用
├── installer/             # 服务器上的应用安装器
├── docs/手册.md           # 详细手册：自行编译、手工安装、卸载
└── AGENTS.md              # 工程约定与不能破坏的边界
```

## 停用与卸载

```sh
/data/open-xiaoai/start-agent.sh stop
```

停止后会解除接管、恢复原生小爱，无需重新刷机。详见 [docs/手册.md](docs/手册.md)。
