怎么把音箱连到这个控制台

刷好补丁固件、能 SSH 登录音箱之后，在你自己的电脑上跑这一条命令（把地址换成音箱的 IP）：

curl -fsSL https://raw.githubusercontent.com/Larryxu001/xiaomi-speaker/main/deploy/install.sh | sh -s -- \
  --speaker root@192.168.1.100 \
  --console {{ console_url }} \
  --token {{ device_token }}

这台控制台的设备令牌：{{ device_token }}　音箱靠它来认你，别发给别人。
